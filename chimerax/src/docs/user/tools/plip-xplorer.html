PLIP-Xplorer 1.0.0

The Language selector offers English, Spanish, German, French, Simplified Chinese, Japanese and Brazilian Portuguese. Changes apply immediately and are remembered, preserving results, styles and manual 3D label placement. Commands, scientific files and external diagnostics retain their original identifiers and language. This selector affects the plugin interface, not ChimeraX or operating-system dialogs.

Open Tools → Structure Analysis → PLIP-Xplorer. Choose an atomic model, the Python executable of a separate environment with PLIP and Open Babel, and a results folder. Click Analyze structure.

The original PLIP engine calculates the interactions. The tool creates a static PDB snapshot of the active coordinate set and displays eight interaction classes using native ChimeraX models. Choose a ligand, toggle interaction types, click rows to select receptor residues, or focus the binding site. Water bridge distances are acceptor–water / donor–water, in Å; hydrogen bonds show donor–acceptor distance.

Every run preserves input.pdb, report.xml, report.txt, engine.log and provenance.json in a new subfolder. Export CSV for all sites or save a .cxs scene. Scenes preserve the drawings; to reopen the table, load report.xml against the matching analyzed snapshot. Do not use these static drawings on a trajectory or after changing atom coordinates. Rigid model movements are supported.

Commands

plip settings python /path/to/plip-environment/bin/python
plip analyze #1
plip analyze #1 output /path/to/results noHydro true wait true
plip load /path/to/report.xml structure #1

Appearance and image export

The Appearance tab offers live preview of backgrounds, native lighting, materials, camera projection, molecular representations, cartoon transparency, element colors, residue/ligand labels and PLIP distance labels. Interaction colors, line radii and dashes are independent for each class. Choose Original, Publication, Dark presentation or Illustration presets, save a default, or save/load a JSON style.

Label text can include the residue name, chain and number. Font, size, color, background boxes and separate residue/distance offsets are configurable. Enable Move individual labels with right-button drag to resolve overlaps before exporting. Disabling it or closing the panel restores the previous mouse binding. Changing styles or filters rebuilds labels, so perform manual placement last. Water bridges display two reported distances in the correct donor/acceptor order. Label and style changes do not alter scientific results. Labels and drawings survive native session saving.

In Export image, choose PNG, TIFF or JPEG, pixel dimensions, viewport aspect ratio, supersampling and JPEG quality. PNG/TIFF support transparent backgrounds. The current view is exported. Optionally isolate the PLIP structure during export; other models' visibility is restored afterward. Background, camera and lighting controls affect the entire scene. Choose manual label colors for the intended background when exporting transparency. The maximum internal render is 100 megapixels.

Keep existing hydrogens only when they have already been prepared. Exact repeatability requires the same prepared structure, PLIP/Open Babel versions and options. This initial adapter handles conventional PDB-sized complexes and the default PLIP small-molecule mode. It rejects multi-character chain IDs and residue numbers beyond PDB limits. It does not expose PLIP's peptide, intra-chain or region analysis options yet.
